# EXIF homepage V1

Upload the contents of this folder to the root of the existing `exif.studio` repository.

## Included

- `index.html`
- `styles.css`
- `script.js`
- `favicon.svg`
- `og-image.jpg`
- `assets/images/`
- `assets/fonts/`

The existing `/atmosphere-audit/` directory should remain in the repository. This package links to it and does not replace it.

## Before publishing

1. Replace the text `LinkedIn / forthcoming` with the final EXIF LinkedIn link when the page URL is available.
2. Keep the Formspree endpoint `https://formspree.io/f/xzzgqbrw` unchanged.
3. TAN Whistling is included locally and is intentionally limited to the short hero signature.
4. The Seasons Roman and Italic carry headings, body copy, navigation and the editorial italic moments. They are prepared in CSS as `the-seasons`. To activate them, create an Adobe Fonts Web Project for `exif.studio` and add its stylesheet inside `<head>` in `index.html`: `<link rel="stylesheet" href="https://use.typekit.net/YOUR-KIT.css">`.
