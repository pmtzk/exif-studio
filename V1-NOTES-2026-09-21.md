## Dear EXIF

Dear EXIF is correspondence, not a conventional contact form.
Initial state asks only for property URL, then expands in-place to reveal:
- “I’m writing because” / textarea
- name
- email
- Send Letter

Form posts to the existing Formspree endpoint.
Draft is preserved in `sessionStorage` while moving between Home and Studio.
On success the block becomes `LETTER RECEIVED. / We’ll take a look from here.` (ES: `CARTA RECIBIDA. / Ahora nos toca observar.`)

The founder-letter route is visible whether or not the form has been submitted.

## Studio

Studio is deliberately short:
- compact EXIF introduction
- personal founder letter
- Write Back → Home / Dear EXIF
- footer

Founder letter keeps lowercase, `&`, informal tone and is visually separate from EXIF’s institutional voice.

## Navigation

Keep the approved asymmetric hamburger and asymmetric X behavior.
The content it opens is replaced with a Vero-inspired editorial index:
- 01 HOME
- 02 STUDIO
- DEAR EXIF as an action, not page 03
- Instagram / LinkedIn
- Based in Mexico / Where the place takes us

Desktop uses large editorial links and typographic hover previews. Mobile uses the same information in a simplified full-screen layout.

## Page transitions

Home ↔ Studio uses a global cover/reveal page transition so route changes do not feel like hard page loads.
The loader is intended only for the first site entry. Returning to Home during the same session skips the loader.

## Language

A global ES/EN toggle is wired across Home and Studio.
- Hero is bilingual.
- The Choice is bilingual.
- Approach cards + outer paragraph are bilingual without removing their interactions.
- Recognition, Dear EXIF, Studio, nav and footer are bilingual.
- Language persists in `localStorage`.

Hero visible copy is intentionally only:
- EN: `A place, made unmistakable.`
- ES: `Un lugar, inconfundible.`

No extra Spanish hero subtitle.
